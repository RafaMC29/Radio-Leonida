Política de privacidad

Última actualización: 16 de noviembre de 2026.

Quién es el responsable

La aplicación «Radio Leonida» pertenece al propietario del canal de YouTube Radio Leonida - GTA VI, que es también su único usuario.

Para qué sirve la aplicación

Sirve para subir vídeos al canal de Radio Leonida y gestionarlos: poner título, descripción y miniatura, organizarlos en listas, leer sus comentarios y consultar sus estadísticas. Usa los servicios de la API de YouTube.

Qué datos trata

  • Los datos del propio canal de Radio Leonida a los que da acceso la API de YouTube: vídeos, listas, comentarios recibidos y estadísticas.
  • Un permiso de acceso (token de OAuth) que Google entrega cuando el propietario autoriza la aplicación.

La aplicación no recoge datos de los espectadores ni de otras personas, no usa cookies y no tiene formularios de registro.

Cómo se usan

Solo para las funciones descritas arriba. Los datos no se venden, no se ceden a terceros y no se usan para publicidad ni para elaborar perfiles.

El uso que hace la aplicación de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Dónde se guardan

El permiso de acceso se guarda de forma privada en el entorno de trabajo del propietario. No se publica ni se comparte.

Cómo retirar el acceso

El propietario puede anular el permiso en cualquier momento desde los ajustes de seguridad de su cuenta de Google. Al hacerlo, la aplicación deja de poder acceder al canal.

Servicios de YouTube

La aplicación usa los servicios de la API de YouTube. Al utilizarla se aceptan las Condiciones del Servicio de YouTube. La política de privacidad de Google está en policies.google.com/privacy.

Contacto

Para cualquier duda sobre esta política, escribe al canal desde su página de información en YouTube.

Volver al inicio

Canal de fans, no oficial. Sin relación con Rockstar Games ni con Take-Two Interactive.
